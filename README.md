## 🎮 Build & Blast

A 2v2 turn-based artillery match where cute worms build battle forts on a
destructible battlefield. Outgun the Storm Syndicate while the storm surge
swallows the low ground.

### Run it

No build step or dependencies — it is plain HTML, CSS and ES modules.

```bash
python3 -m http.server 3002
# open http://localhost:3002
```

### Controls

| Action | Desktop | Touch |
| --- | --- | --- |
| Aim / fire | Drag from your worm, release | Drag on the battlefield, release |
| Move | `A` / `D` | ◀ / ▶ buttons |
| Jump | `Space` | ▲ button |
| Build mode | `B` or **BUILD** | **BUILD** |
| Select weapon / piece | `1`–`3` | Tap a hotbar card |
| Cycle material | `4` | Tap the material chip |
| Rotate ramp | `R` | **ROTATE** |
| End turn | **END TURN** | **END TURN** |

### Features

- Turn-based 2v2 artillery with wind, bazooka, grenade and pump shotgun.
- Fortnite-style grid building: walls, floors and ramps in wood, brick or metal.
- Fully destructible pixel terrain, supply crates and material regeneration.
- Storm surge raises the water every two rounds from round 3.
- AI squad that builds cover and arcs ballistic shots.
- Responsive HUD and touch controls for phones, tablets and desktop.
